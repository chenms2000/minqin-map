# Project instructions

## Long-term maintenance

- Before changing the project, read `docs/PROJECT_STATUS.md`, `docs/TODO.md`, `docs/DECISIONS.md`, and `docs/MAINTENANCE.md`.
- Keep changes focused on the current approved task. Do not modify unrelated files.
- Preserve existing user changes and never overwrite secrets, credentials, or environment files.
- Run the most relevant available checks after implementation and report the exact results.
- After completing meaningful work, update `docs/PROJECT_STATUS.md` and `docs/TODO.md`.
- Record durable architectural or product decisions in `docs/DECISIONS.md`.
- Append a concise dated entry to `docs/MAINTENANCE.md` describing changes, checks, and remaining risks.
